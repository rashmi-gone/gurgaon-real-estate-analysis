# Gurgaon Real Estate Market Analysis

Exploratory data analysis of 19,515 property listings in Gurgaon using Python.

## Objective
Clean the raw listing data and answer 10 pricing questions to understand what drives property prices across sectors.

## Dataset
19,515 property listings. Source: [add the source, e.g. Kaggle link, or write "provided dataset"]

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Cleaned the data: fixed data types and removed duplicates
- Answered 10 pricing questions using Pandas groupby analysis
- Visualised the results with Matplotlib and Seaborn

## Key Findings
- Sector 42 had the highest average price (about ₹50 crore)
- Area and price have a correlation of 0.63
